Adds random variation of ±(value/2)ms to Silence Duration. Example: 1000ms adds ±500ms variation, making timing more human-like. Cannot exceed Silence Duration.

If audio does not resume, the extension will retry clicking the button at this interval (in seconds). Set to 0 to disable retries.

When enabled, monitors audio across all open tabs. When disabled, only monitors the selected tab.

When disabled (recommended), the extension will automatically lock to the first tab where it successfully clicks the button, improving performance. When enabled, it continues searching all tabs every time.

Select which tab to monitor for audio. The extension will only work on this specific tab.
